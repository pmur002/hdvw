Introduction

A data visualisation presents data values in a visual format. In an effective data visualisation, this allows features of the data to be perceived very rapidly and without conscious effort. For example, Table 1 shows data on the crime rate for youth offenders in New Zealand, for the ages 14 to 16, for each year from 2011 to 2021. With this purely text-based, tabular presentation of the data, it is difficult to answer the following questions:

Does the crime rate decrease monotonically for all ages?

Is the crime rate for 15-year-olds always greater than the rate for 14-year-olds and less than the rate for 16-year-olds?

By contrast, with a simple line plot data visualisation like Figure 1 we can answer the questions easily and immediately.
