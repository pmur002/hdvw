Visual objects are relatively complex data symbols that have
a learned decoding.

Encoding data values as visual objects is effective because
the learned decoding provides a pre-existing decoding from the
data symbol to data values.
This can support an explicit encoding and can
remove the need for axes and legends to explain the decoding.

However, visual objects may be distracting if they are
not related to any encoding of data values and the increased
complexity can make decoding more difficult.

It is also important not to create a conflict between
an explicit encoding and a learned decoding.  That will result
in confusion or incorrect decoding of the data symbols.
