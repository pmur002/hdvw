The effectiveness of a data visualisation may depend on more than
just the accuracy and capacity of visual features.

A **congruent** encoding is one where data values are *explicitly* encoded in
a way that is consistent with an *implicit* decoding of the visual feature.

A data visualisation will be more effective if it is visually congruent, for
example,
data symbols are larger for larger data values or 
data symbols only change if the data values change.

A **dissonant** encoding is one where data values are *explicitly*
encoded in a way that is *inconsistent* with an *implicit* decoding.

A data visualisations will be less effective if it is visually
dissonant.
