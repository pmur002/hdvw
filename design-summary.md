Just as we can encode data values to visual features, in order to 
communicate information about the data,
we can encode non-data information to visual features, in order to
communicate important aspects of the structure of a data visualisation.

The structure or organisation of a data visualisation, or the
importance of specific elements,
can be effectively encoded as the position or colour of different elements
of the data visualisation.

Communicating structure and importance helps the viewer to navigate
within the data visualusation, which makes it easier to decode
information from the data symbols within a data visualisation.
